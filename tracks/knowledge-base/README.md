# 知识管理线路

中文 | [English](README.en.md)

## 线路问题

当知识准备在未来真实任务中被人或 Agent 找到、读取、判断和复用时，怎样组织、验证、更新和退出，才能形成可持续的组织记忆？

这条线路处理的是“长期知识复用”，不是所有内容对象，也不负责媒体作品、项目临时状态、完整来源归档或通用内容管理。

## 已观察到的候选主干

- 知识的价值由下一次真实任务中的复用证明，不由入库动作证明。
- 内容边界应由独立复用、更新和失效决定，而不是由文件、标题或固定字数决定。
- Agent 必须取得实际内容，摘要、清单和占位入口不能冒充知识可用。
- 有效知识、失效知识、来源和索引需要明确关系，不能依赖平台界面暗示。
- 规则必须允许真实反例修正，领域策略不能冒充跨领域不变量。

这些判断目前只在知识管理及投标知识复用实践中形成，不代表已经通过其他线路验证。

## 本地验证边界

企业知识库、投标材料和真实复用结果继续留在对应业务项目。公共仓只记录脱敏后的触发条件、失败机制、验证结果和规则去向，不复制客户资料、知识组件或标书。
