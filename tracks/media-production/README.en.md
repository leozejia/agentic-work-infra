# Media Production Track

[中文](README.md) | English

## Track Question

How can a judgment triggered by news, research, or personal experience become a credible work, channel derivatives, and real feedback through agent collaboration without mixing platform state, personal content, and work-in-progress state?

This track studies media production methods. It does not store an author's articles, images, account information, publishing links, traffic records, or platform automation configuration.

## Local Validation Field

The personal media repository continues to own real content, personal voice, channel-ready drafts, assets, and platform operating methods. It is the local validation field for this track, not a dependency of the public repository. Validation does not require content migration.

## Observed Candidate Structure

- Separate signals, primary sources, and the author's judgment. A trend cannot replace a claim.
- One complete article owns the argument and evidence boundary. Channel versions may select, reorganize, or shorten it, but cannot invent facts absent from the article.
- Separate durable work assets from live platform state. The repository keeps reusable content; the platform keeps publication, links, and performance.
- Automation may prepare drafts and check formatting. Public publishing, interaction, and irreversible decisions require the person's current authorization.
- Feedback should change the next topic, argument, or distribution choice. It should not become a permanent status ledger.

These judgments come from one personal media practice and currently remain media track rules. They become cross-track candidates only when the same work constraint appears in another independent track.

## Current Method and Evidence

- [Agent-Assisted Media Production](method.en.md): defines the relationship between signals, author judgment, canonical copy, channel derivation, publishing authorization, and feedback.
- [Canonical Article and Channel Derivative Validation](validations/article-derivation.en.md): tests continuation, source-of-truth selection, results, feedback, and transfer against one completed real content task.

This track migrates only roles, constraints, and redacted conclusions. Articles, author profiles, channel configuration, platform accounts, and automation implementations remain in their original projects.

## Questions to Validate

- Can a new agent recover the current claim, evidence boundary, and next action without old chats?
- When sources, canonical copy, channel derivatives, and temporary state coexist, can the agent select the correct source of truth?
- Does platform feedback improve future work, or only create more record-keeping?
- Can personal voice be separated from the shared media method so that method transfer does not copy the author's identity?
