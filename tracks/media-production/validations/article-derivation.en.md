# Canonical Article and Channel Derivative Validation

[中文](article-derivation.md) | English

## Validation Target

A completed series article began with the author's product experience and public technical sources, formed one judgment about the position of independent developers, then produced canonical copy, a long-form channel version, mobile image copy, and final images.

The personal media project continues to own the original text, images, accounts, and platform state. This record retains only the minimum facts needed to judge the method.

## Actual Path

1. Personal experience supplied the problem. Public project material supported a technical division of responsibility, not the author's business conclusion.
2. The series document limited this article's role in the causal chain and prevented it from consuming later questions early.
3. Canonical copy owned the claim and evidence boundary. Channel drafts selected or reorganized it and were not defined as a second article.
4. The image version split the same judgment into mobile reading steps. Final assets remained separate from temporary candidates.
5. Publication and performance were not written back into the content repository. Final Xiaohongshu publication remained a human action.
6. Human feedback about automated publishing risk changed the later tool contract. Filling, saving a draft, and publishing became separate actions.

## Five Tests

### Continuation Test: Pass

A new agent can read the media workflow, current execution surface, and one series document to recover the current series, the article's independent question, accepted baseline, non-goals, and stopping point. It does not need full chat history or every historical article.

### Source-of-Truth Test: Pass

Canonical copy owns the argument. The series document owns the long-term thesis. The current execution surface owns the next action. Channel drafts own derived expression. The platform owns live publication state. Explicit precedence prevents several files from maintaining the same fact.

### Result Test: Partial Pass

Canonical copy, channel drafts, and final assets form deliverables that a person can inspect and use, and the publishing authorization boundary is explicit. Platform exposure, interaction, and later conversion remain outside the repository. This validation did not import those outcomes, so it cannot judge distribution performance.

### Feedback Test: Pass Through One Safety Counterexample

The user rejected automation that crossed the human review surface. The feedback became an executable rule rather than a chat note: high-risk platforms allow automated filling or draft saving, while final publication remains human. Feedback changed the formal method or tool contract.

### Transfer Test: Partial Pass

The roles of current execution surface, long-term thesis, canonical copy, channel derivatives, and live platform state do not depend on one platform. Filenames, card count, publishing tools, and brand treatment still depend on the current media project and channel, so they remain in the track or real project.

## Rule Disposition

### Enter Cross-Track Candidates

- The current execution surface stores the goal, accepted baseline, next action, and stopping point. Full history remains elsewhere.
- Formal sources of truth, derived views, and live external state remain separate. Each fact has one authoritative owner.
- A formal entry point and a human-inspectable result prove completion. A generated file or success message does not.

### Remain in the Media Track

- Canonical copy must exist before channel derivatives. Channel versions cannot add facts absent from the article and its sources.
- Public publishing and interaction require the person's current authorization. High-risk platforms retain a final human review surface.
- Platform data is read when needed instead of stored in a permanent content calendar or performance ledger.

### Continue Observation

- How platform feedback can improve future topics and distribution without creating a status ledger.
- Whether personal voice calibration can be separated from the author and remain effective for different authors.
