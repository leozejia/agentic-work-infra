# Lessons from Work

记录重复出现的失败模式。出现 3 次后晋升到 AGENTS.md 或项目规范。

## 使用说明

**何时记录**：
- Agent 修复了前一周/两周内出现过的同一问题
- 同一类型错误出现多次

**记录格式**：
```markdown
### [具体规则名称]

**规则**：[一句话说应该怎么做]
- 证据1：<commit/任务标识> + 简要说明
- 证据2：...
- Seen N× (YYYY-MM-DD, YYYY-MM-DD, ...)
- 做对示例：<commit/任务标识>（这条规则被正确执行的一次，可模仿）
```

"做对示例"让规则可模仿而不只是可回避；没有时可省略此行。

**晋升标准**：
- 出现 ≥3 次 → 移到 AGENTS.md 或相关规范
- 在此保留引用
