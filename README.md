# Agentic Work Infra

> **Agent 时代，人和 Agent 协同的核心是：双方面对同一个工作状态，共同观测、操作、修正和演化，而不是各自维护一套。**

## 这个项目研究什么

本项目研究 Agent 时代人和 Agent 如何协同完成真实工作——怎样分工、怎样保持工作状态可观测、怎样避免协同结构在实践中跑偏。

知识库、投标等是研究课题（track），用于在真实工作中验证协同模型。
